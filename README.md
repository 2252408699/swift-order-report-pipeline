# Swift Order Report Pipeline

This command-line project turns a small JSON order export into a report. It uses `filter`, `map`, `flatMap`, `compactMap`, `reduce`, and `reduce(into:)` for distinct data-processing jobs and verifies the output with eight checks.

## Requirements

- macOS 13 or later
- Swift 5.9 or later (`swift --version`)

## Run

```bash
git clone https://github.com/2252408699/swift-order-report-pipeline.git
cd swift-order-report-pipeline
swift run
```

A successful run ends with `All order report checks passed.`
